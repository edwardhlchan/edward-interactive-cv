# Tech CV Crafting & Audit Guide

> **Core Philosophy:** A CV is **not** a diary or an academic report; it is a **high-stakes product marketing document**. The hiring audience (e.g., General Managers, Senior Engineering Leads, HR screening thousands of resumes) judges your professionalism, attention to detail (*見微知著*), and problem-solving maturity in under 10 seconds.

---

## 1. Golden Rules of Tech CV Strategy

### Rule 1: Zero-Cringe Professional Identity
- **Email:** Strict name-based standard (`firstname.lastname@domain.com` or `firstname.initials.lastname@...`). Never use gamer handles, slang, or birth years (e.g., `edwardcc082009@...` $\rightarrow$ `edward.hl.chan@outlook.com` / `contact@edwardchan.dev`).
- **GitHub / LinkedIn Handles:** Must match or clearly reflect your real name (`github.com/edhlchan` or `github.com/edwardchan-dev` vs. `github.com/lmaodick1239`).
- **Custom Domains:** Host live projects on clean professional domains (e.g., `edwardchan.dev` vs. obscure/ad-hoc subdomains).

### Rule 2: Precision in Academic & Professional Identity
- **Accurate Job/Student Title:** State current reality with clear aspiration (e.g., *"Information Technology and Data Science Student | Aspiring Technology Operations & Cybersecurity Professional"*). Do not claim a degree or title you haven't started (e.g., do not write "Computer Science Student" if currently in a Data Science / ApL diploma track).
- **Translate Niche Credentials into Market Value:**
  - *Distinction II* $\rightarrow$ `"Top Performer (Grade: Distinction II, awarded to the top 4% of students)"`
  - *CLAP-TECH Pathway* $\rightarrow$ `"A Jockey Club Multiple Pathways Initiative – Offered by HKBU & Co-designed by IBM"`
- **Academic Strengths Framing:** Highlight high-impact subjects and suppress irrelevant noise.
  - *Bad:* Listing all subjects or mediocre scores (e.g., Level 3 Math as a "Key Result").
  - *Good:* `"Academic Strengths: Achieved top-tier results in analytical and language subjects, securing Level 5 in ICT and Level 5 in English Language."`

### Rule 3: Visual Rhythm & Formatting Integrity (*見微知著*)
Hiring managers extrapolate code quality from CV layout. Inconsistent formatting implies sloppy coding.
- **Micro-Consistency:** Equal paragraph weights, uniform line-heights ($1.35 - 1.5$), balanced column margins, and consistent font hierarchies.
- **Never "Eyeball":** Use exact pixel/rem grids, automated CSS checks, and visual snapshot reviews rather than arbitrary manual guessing.
- **Section Symmetry:** Avoid jarring mismatches where one section has 5 dense lines while an adjacent block has 1 tiny fragmented sentence.

### Rule 4: Action-Oriented Project Bullet Points (STAR Framework)
Transform coursework and hobby code into proof of engineering capability:
- **Strong Action Verbs:** *Engineered, Automated, Developed, Analyzed, Remapped, Deployed*.
- **Tech Stack in Title:** `Project Name | Tech Stack (e.g., Cloudflare Workers, D1 SQLite, JS)`.
- **Live Proof Points:** Always provide clickable, working live demos and clean GitHub repository links.

### Rule 5: Dual-Channel Delivery
1. **Print/ATS-Ready PDF (1–2 Pages):** Clean, machine-parsable, standard A4 layout.
2. **Interactive Cloud-Hosted Web CV:** Deployed on edge infrastructure (e.g., Cloudflare Workers, GitHub Pages) demonstrating actual deployment skills.

## 2. Comprehensive Audit Checklist

Before finalizing any CV, execute this 6-point audit:

| Check | Item | Pass Criteria |
|---|---|---|
| **1** | **Contact & Links** | Real-name email, professional GitHub/LinkedIn, international phone code (`+852`), live clickable URLs. |
| **2** | **Headline & Summary** | Clear target role + academic standing + standout metric (e.g., Top 10 BOTS finalist) in 3–4 lines. |
| **3** | **Education & Badging** | Co-designed corporate partners (IBM, HKBU), top % rankings spelled out, positive academic framing. |
| **4** | **Projects & Experience** | Active verbs, business/operational impact, tech stack tags, live demo & repo links. |
| **5** | **Skills Taxonomy** | Categorized cleanly (*Languages*, *Cybersecurity & IT Ops*, *Tools & Frameworks*, *Modern Workflows*). |
| **6** | **Typography & Rhythm** | Zero typos, consistent bullet indents, uniform line spacing, print-ready CSS pagination. |
